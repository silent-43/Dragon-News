# 📰 Dragon News

Dragon News is a modern news website built with React.js.  
The project focuses on creating a clean, responsive, and user-friendly news portal interface.

## 📌 Features

- 📰 Latest News section
- 📢 Scrolling latest news marquee
- 📅 Dynamic date formatting
- 🧭 Client-side routing
- 📱 Responsive design
- 🎨 Tailwind CSS styling
- 🌈 DaisyUI components
- 🔥 Firebase integration
- ⚡ Fast development with Vite

## 🛠️ Technologies Used

### Frontend

- React.js
- React Router
- Tailwind CSS
- DaisyUI
- Vite
