# 📰 Dragon News

Dragon News is a modern, responsive news portal built with React.js.
The project provides a clean and user-friendly interface for browsing
news articles across different categories.

The project also includes Firebase Authentication and is deployed using
Firebase Hosting.

## 🚀 Live Demo

🔗 https://dragon-news-c8d63.web.app

## 📌 Features

- 📰 Latest News section
- 🗂️ Category-based news browsing
- 📢 Latest news scrolling marquee
- 📅 Dynamic date formatting
- 🧭 Client-side routing
- 📖 News details / Read More functionality
- 📤 News sharing functionality
- 🔐 Firebase Authentication
- 👤 User login and registration
- 👤 User profile image
- 📧 Display authenticated user's email
- 🚪 User logout functionality
- 📱 Responsive user interface
- 🎨 Modern UI with Tailwind CSS
- 🌈 DaisyUI components
- ⚡ Fast development with Vite
- 🔥 Firebase integration
- 🚀 Firebase Hosting deployment

## 🛠️ Technologies Used

### Frontend

- React.js
- React Router
- Tailwind CSS
- DaisyUI
- Vite

### Backend / Services

- Firebase
- Firebase Authentication
- Firebase Hosting

## 🔥 Firebase Features

Firebase is used in this project for:

- 🔐 User Authentication
- 🚀 Hosting and deployment

## 📅 Date Formatting

The project uses `date-fns` for formatting and displaying news
publication dates in a user-friendly format.

## 📢 Latest News Marquee

A scrolling latest-news section has been implemented using
`react-fast-marquee` to display breaking/latest news continuously.

## 🧭 Routing

React Router is used for client-side navigation between different
pages and news categories.

## 🎨 UI & Styling

The user interface is built using:

- Tailwind CSS
- DaisyUI
- React Icons

The design is responsive and works across different screen sizes.

## 🔐 Authentication

Firebase Authentication is integrated to provide:

- User registration
- User login
- User logout
- Authenticated user information
- User profile image
- User email display

## 🚀 Firebase Hosting

The project is deployed using Firebase Hosting.
